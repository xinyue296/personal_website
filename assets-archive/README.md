# Archived assets

Card artwork no longer used on the site. Kept in the repo but outside `public/`,
so it is not served or indexed.

- `projects/UHelper.png` and `projects/PersonalPortfolio.png` were bespoke card
  images. Retired on 2026-10-11 so every project card uses the same generated
  style, with Dr. Mario the one exception because it shows the actual game.

To bring one back, move it into `public/assets/projects/` and add an
`image:` line to that project's frontmatter.
